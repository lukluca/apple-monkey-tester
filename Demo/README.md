# Demo

A minimal two-page iOS app used to exercise `MonkeyTester` end-to-end on a real XCUITest UI-testing session (something `swift test` on the package alone can't do — see the root [README](../README.md#status)).

- **Home** — safe content only: a counter button and a link to the crashing page.
- **Crash** — a red "Crash" button that reads past the end of a 3-element array on purpose (`items[10]`), which traps and terminates the app.

`DemoAppUITests/DemoAppMonkeyTests.swift` launches the app and runs `MonkeyTester` against it for 500 events with a fixed seed; the test asserts the app is no longer in the foreground afterwards, i.e. the monkey's random taps/swipes reached the Crash button.

## Regenerating the Xcode project

The `.xcodeproj` is generated by [XcodeGen](https://github.com/yonaskolb/XcodeGen) from `project.yml` and isn't committed (see the repo's `.gitignore`):

```bash
brew install xcodegen   # once
cd Demo
xcodegen generate
```

## Running

```bash
cd Demo
open DemoApp.xcodeproj   # run the app normally on a simulator, or:
xcodebuild test -project DemoApp.xcodeproj -scheme DemoApp -destination 'platform=iOS Simulator,name=iPhone 17 Pro'
```
